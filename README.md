# 社内文書検索アシスタント(設計ポートフォリオ)

社内規程などの文書に、根拠つきで答える検索アシスタントの、設計と検証の記録です。
根拠が無い質問には答えを作らず、「回答なし」と次の行動を返すことを、いちばん重く見ています。

公開ページ: https://yumeyume90.github.io/docsearch-insight/

## 内容

- 解決したかったこと
- 画面のモック(回答・回答なし・失敗を、ダミーデータで再生)
- 仕組み(取り込み→ベクトル化→保存→検索→生成)
- 設計判断(検索方式・プロバイダ・ベクトルストア)
- 品質の担保(受け入れ基準 F-1〜F-6、テストの方針)
- AIと一緒に作るための決めごと
- できないこと・限界

## 技術

RAG(ベクトル検索) / Claude / OpenAI Embeddings / Supabase(pgvector) / TypeScript

## 補足

- 画面・文書名・数値はすべてダミーです。
- 本体のソースコードは公開していません。このリポジトリは、デモページ(`index.html`)のみです。
